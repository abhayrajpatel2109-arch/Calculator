# Calculator
A clean, responsive, and easy-to-use web calculator built with HTML, CSS, and JavaScript.
A lightweight, modern, and fully responsive calculator application built using HTML5, CSS3, and JavaScript.
--------------------------------------------------
## ✨ Features

* **Basic Arithmetic:** Supports addition (+), subtraction (-), multiplication (*), and division (/).
* **Responsive UI:** Clean design that works seamlessly on desktop and mobile screens.
* **Keyboard Support:** Allows key input directly from the physical keyboard.
* **Instant Clear & Delete:** Includes 'C' (Clear All) and 'DEL' (Backspace) buttons.
---------------------------------------------------
## 🛠️ Tech Stack

* **HTML5:** Structure of the calculator.
* **CSS3:** Styling, grid layout, and modern UI.
* **JavaScript (ES6):** Logic and evaluation.
